Detailed Description

Polyfill std::unreachable

We need something like std::unreachable to tell the compiler that some macros, e.g. FAIL or SKIP, do not continue execution in normal manner, and should handle it as such, e.g. not warn if there is no return from non-void function after a FAIL or SKIP.
