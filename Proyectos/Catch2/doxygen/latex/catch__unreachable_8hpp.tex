\doxysubsection{Detailed Description}
Polyfill {\ttfamily std\+::unreachable}

We need something like {\ttfamily std\+::unreachable} to tell the compiler that some macros, e.\+g. {\ttfamily FAIL} or {\ttfamily SKIP}, do not continue execution in normal manner, and should handle it as such, e.\+g. not warn if there is no return from non-\/void function after a {\ttfamily FAIL} or {\ttfamily SKIP}.
