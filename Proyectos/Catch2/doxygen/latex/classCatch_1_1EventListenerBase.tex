\doxysubsection{Detailed Description}
Base class to simplify implementing listeners.

Provides empty default implementation for all \doxylink{classCatch_1_1IEventListener}{IEvent\+Listener} member functions, so that a listener implementation can pick which member functions it actually cares about.
