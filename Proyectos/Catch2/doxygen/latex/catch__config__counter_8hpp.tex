\doxysubsection{Detailed Description}
Wrapper for the CONFIG configuration option

When generating internal unique names, there are two options. Either we mix in the current line number, or mix in an incrementing number. We prefer the latter, using {\ttfamily \+\_\+\+\_\+\+COUNTER\+\_\+\+\_\+}, but users might want to use the former.
