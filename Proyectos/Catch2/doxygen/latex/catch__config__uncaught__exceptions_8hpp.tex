\doxysubsection{Detailed Description}
Wrapper for UNCAUGHT\+\_\+\+EXCEPTIONS configuration option

For some functionality, Catch2 requires to know whether there is an active exception. Because {\ttfamily std\+::uncaught\+\_\+exception} is deprecated in C++17, we want to use {\ttfamily std\+::uncaught\+\_\+exceptions} if possible.
