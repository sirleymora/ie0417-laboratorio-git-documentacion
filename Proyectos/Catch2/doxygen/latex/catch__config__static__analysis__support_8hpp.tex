\doxysubsection{Detailed Description}
Wrapper for the STATIC\+\_\+\+ANALYSIS\+\_\+\+SUPPORT configuration option

Some of Catch2\textquotesingle{}s macros can be defined differently to work better with static analysis tools, like clang-\/tidy or coverity. Currently the main use case is to show that {\ttfamily SECTION}s are executed exclusively, and not all in one run of a {\ttfamily TEST\+\_\+\+CASE}.
